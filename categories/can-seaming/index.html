SELECTION CONSIDERATIONS

Treat the can body and end as one format.

Matching Containers, Closures and Sealing Equipment ↗

Supply the container supplier's dimensions and seam information. A diameter range is not a substitute for checking the complete can-and-end combination.

Seam assessment considers examination and measurements together. Use the container supplier's requirements and a suitable evaluation process for the selected can-and-end format.

Useful details for your enquiry

  • Which can body and end will be used?
  • Which configuration matches that format?
  • What seam specifications and evaluation method apply?
