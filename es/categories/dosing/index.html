Equipos de dosificación

El equipo de dosificación prepara porciones para una bolsa receptora, botella o paso de envasado posterior. El material, la cantidad objetivo y el método de recolección de cada dosis definen el punto de partida.

CONSIDERACIONES DE SELECCIÓN

Defina la porción y el paquete receptor.

Definir una Aplicación de Llenado o Dosificación ↗

Especifique el peso o volumen objetivo y cómo se comprobará cada dosis. Incluya las características del flujo de material y la precisión requerida para su aplicación.

Incluya la altura del paquete receptor, la abertura de llenado y el suministro aguas arriba. Para diseños de doble canal o elevador, muestre cómo llega el material a la etapa de dosificación y cómo se recolectan las porciones.

Dónde encaja esta tarea en tu proceso

Una dosis medida todavía necesita un recipiente o bolsa receptora. Identifica si tu siguiente paso es llenar un recipiente, formar un sobre o cerrar una bolsa llena y muestra cómo la porción llega a ese paso.
