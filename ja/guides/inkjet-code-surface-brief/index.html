インクジェット コーディング: 表面とコードの概要を準備する

実際のパッケージ表面と印刷する正確なメッセージを使用してコーディングの調査を開始します。印刷領域とその後のコードの処理は、テキスト自体と同じくらい重要です。

実際のサーフェスを特定します

包装材料と塗装・仕上げについて記載する。 印刷時の状態を,湿度,油分,温度などを含めて記述する。 2つのパッケージが同じ広い材料名を持つ場合,異なる表面を示すことがある。 従って,インキの選択と付着性は実際の試料に対して議論する必要がある。

フルサイズのコード例を送信します

日付、バッチ情報、またはその他のテキストを、意図したサイズと位置で表示します。使用可能な印刷領域とその近くの継ぎ目、折り目、または曲線を含めます。リストされている H2 構成については、コードの高さをその製品仕様と比較してください。バーコード、QR コード、複数の言語、またはデータ機能が必要な場合は、お問い合わせにそれらの要件を含めてください。

パッケージがどのように提示されるかを説明する

現行の符号化製品は,ハンドヘルドインクジェットプリンタである。 また,作業者のアクセスと作業中の表面の位置について述べた。 操作の概要を 手持ちの装置と一致させておく。 異なる運用形態の要求はそれぞれの議論が必要である。

印刷後の寿命について説明します

印刷された領域が最初に触れた時,包装した時,または擦った時,そして貯蔵と輸送の中で何を経験したかを教えてくれ。 これらの条件は評価する結果を定義するのに役立つ。 指定した処理条件を通して,新しいコードの読み取り性と耐久性を評価する。 実際の包装と予定の取り扱いについてのサンプル評価を聞く。

準備する詳細

決定準備する情報なぜ重要なのか
表面材質、コーティングおよび印刷時の状態インクからパッケージへの質問を定義します
コード正確なテキスト、寸法、位置使用可能な印刷領域を定義します
プレゼンテーションオペレーターが荷物を保持または到達する方法問い合わせをハンドヘルドでの使用に合わせて維持します
印刷後最初の接触とその後の暴露耐久性要件を定義します

H2 のお問い合わせには、印刷されていないパッケージ サンプルとフルサイズのコード例を提供してください。リストにないインクやソフトウェアの機能を想定せずに、意図した結果を指定します。
