Inkjet-Codierung: Vorbereitung der Oberfläche und Code-Brief

Beginnen Sie eine Codierungsanfrage mit der tatsächlichen Paketoberfläche und der genauen Nachricht, die gedruckt werden soll. Der Druckbereich und was danach mit dem Code passiert, ist genauso wichtig wie der Text selbst.

Identifizieren Sie die tatsächliche Oberfläche

Geben Sie das Verpackungsmaterial und etwaige Beschichtungen oder Oberflächen an. Beschreiben Sie den Zustand beim Drucken, einschließlich Feuchtigkeit, Öl oder Temperatur, sofern relevant. Zwei Pakete mit demselben breiten Materialnamen können unterschiedliche Oberflächen aufweisen. Farbauswahl und Haftung müssen daher für die tatsächliche Probe besprochen werden und nicht für alle Kunststoffe oder Kartons angenommen werden.

Senden Sie ein Codebeispiel in Originalgröße

Zeigt das Datum, Chargeninformationen oder anderen Text in der vorgesehenen Größe und Position an. Berücksichtigen Sie den nutzbaren Druckbereich und die umliegenden Nähte, Falten oder Rundungen. Vergleichen Sie für die aufgeführte H2-Konfiguration die Codehöhe mit den Produktspezifikationen. Wenn Sie Barcodes, QR-Codes, mehrere Sprachen oder Datenfunktionen benötigen, geben Sie diese Anforderungen in der Anfrage an.

Erklären Sie, wie das Paket präsentiert wird

Das aktuelle Codierungsprodukt ist ein tragbarer Tintenstrahldrucker. Beschreiben Sie den Zugang des Bedieners und die Position der Oberfläche während der Markierung. Halten Sie die Handhabungsanweisung an einem Handgerät ausgerichtet. Jede Anfrage nach einer anderen Betriebsvereinbarung erfordert eine eigene Diskussion.

Beschreiben Sie das Leben nach dem Drucken

Sagen Sie uns, wann der bedruckte Bereich zum ersten Mal berührt, verpackt oder gerieben wird und was ihm bei Lagerung und Transport widerfährt. Diese Bedingungen helfen dabei, das auszuwertende Ergebnis zu definieren. Bewerten Sie sowohl die Lesbarkeit als auch die Haltbarkeit von frischem Code anhand der von Ihnen angegebenen Handhabungsbedingungen. Fragen Sie nach einer Musterbewertung für das tatsächliche Paket und die beabsichtigte Handhabung.
