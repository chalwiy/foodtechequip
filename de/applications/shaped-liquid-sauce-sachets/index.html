PAKET & PROZESS

Planung geformter Beutel für Flüssigkeiten und Saucen

Ein geformter Beutel kombiniert einen Materialanteil mit einer bestimmten Folienkontur und einem Siegelbereich. Das geformte Beutelprodukt von FTE bietet den Ausgangspunkt für die Ausrüstung. Die fertige Verpackung muss für die vorgesehene Flüssigkeit oder Soße besprochen werden.

Beginnen Sie mit dem Inhalt des Beutels

Beschreiben Sie die Flüssigkeit oder Soße beim Abfüllen, die Zielportion und alle Zutaten, die den Fluss beeinflussen. Unterscheiden Sie die gewünschte Dosis anhand der Außenabmessungen der Packung. Eine Silhouette kann eine Präsentation suggerieren, die ausgefüllte Fläche und die umlaufende Versiegelung müssen aber trotzdem zum eigentlichen Produkt passen.

Beschreiben Sie die Kontur als Paket

Liefern Sie eine Zeichnung mit dem fertigen Schnittumriss, dem vorgesehenen versiegelten Rand und der zum Füllen verfügbaren Fläche. Markieren Sie schmale Abschnitte und Kurven, die für das Design wichtig sind. Dies ist ein nützlicherer Ausgangspunkt als eine dekorative Darstellung ohne Abmessungen.

Zusätzliche Merkmale erkennbar machen

Öffnungsverhalten, Druckausrichtung und ein Gießpunkt können für Ihr Projekt wichtig sein. Markieren Sie sie als Anforderungen und besprechen Sie deren Machbarkeit mit der vorgeschlagenen Konfiguration. Halten Sie diese Anforderungen getrennt von dem, was bereits für die Film-Vertikalmaschine beschrieben wurde.

Ausrüstung und Verbrauchsmaterialien im Geltungsbereich halten

Geben Sie die beabsichtigte Filmspezifikation an und geben Sie an, ob eine einzelne Form oder mehrere Formate verwendet werden. Klären Sie, was das Ausrüstungsangebot abdecken soll und ob es sich bei der Lieferung von Verbrauchsmaterialien um eine separate Anfrage handelt. Bewerten Sie das komplette Paket und Material, bevor Sie das Bildmaterial fertigstellen oder davon ausgehen, dass ein Setup alle Konturen abdeckt.
